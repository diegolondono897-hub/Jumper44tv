# Jumper44tv

**Jumper44tv** es una aplicación de streaming optimizada para Android que ofrece películas viejas y nuevas, con soporte para reproducción en línea y fuera de línea.

## Características principales:
- 🎬 Streaming gratuito con opciones premium
- 📥 Descarga de contenido para visualización offline
- 🔄 Actualización automática de contenido
- 📺 Reproducción adaptable (vertical y horizontal)

## Tecnologías utilizadas:
- `Kotlin` + Jetpack Compose
- MVVM + Clean Architecture
- ExoPlayer para reproducción multimedia
- Room Database para almacenamiento local
- Retrofit para integración de APIs
